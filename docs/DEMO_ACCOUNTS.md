# Local demo accounts

These accounts are created by `make seed` for local development and testing only.

| Role | Email | Password |
| --- | --- | --- |
| Regular learner | `learner@examme.test` | `learner` |
| Administrator (`*`) | `admin@examme.test` | `admin` |
| Root | `root@examme.test` | `root` |

The seed command clears and recreates the shared local/test catalog, including exams, tags, questions, sessions, activities, and rating marks.
